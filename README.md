# 💰 Telegram Expense Bot

![Demo](docs/tgbot.gif)

## Features
- Add expenses with `/add 5.50 coffee`
- View monthly statistics with `/stats`
- Secure token storage with `.env`

## How to Run
```
pip install -r requirements.txt
python bot.py
```
